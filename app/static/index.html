Ahordian User Guide

Everything you need to get started and master Ahordian Acoustic Guitar Suite.

Getting Started

Ahordian runs entirely in your browser. Audio is processed locally via the Web Audio API — no plugins needed.

  • Click Start Detection on the Tuner & Detector screen and allow microphone access.
  • Play a note on your guitar — pitch is detected in real time using autocorrelation (YIN-style).
  • Use the topbar volume slider & mute button to control all audio at any time.

Best results: quiet room, mic 15–30 cm from soundhole.

Tuner & Detector

  • Current Note — Western (A, B, C…) and Sargam (Sa, Re, Ga…) simultaneously.
  • Physics Needle — Centred = in tune. Left = flat, right = sharp.
  • Estimated Chord — Rolling window of detected notes guesses the chord.
  • Record to Tape — Captures stable notes for export or replay.
  • Replay (64 max) — Replays up to 64 detected notes on fretboard with audio.

Jam Station & Virtual Band

Located on the Interactive Fretboard screen. Generates a full backing track in your browser.

  • Progression — 12-Bar Blues, Pop I-V-vi-IV, Jazz ii-V-I.
  • Key — Transposes the progression to any key.
  • Tempo slider — BPM changes apply on the next beat. The engine never restarts.
  • Guitar / Drums Volume — Independent gain for each instrument.
  • Soloing Guide — Highlights Pentatonic, Blues, or triad positions as chords change.

Samples load from static/audio/guitar/acoustic/. If absent, Karplus-Strong synth activates automatically.

Metronome

  • Always in the topbar — available on every screen.
  • BPM (40–250), time signature (4/4, 3/4, 6/8), sound (Beep, Wood, Tick).
  • LED syncs via Web Audio look-ahead scheduler — zero drift.

Chord, Scale & Circle Explorers

Chord Explorer: Search by root + quality. Play any voicing to hear it.

Scale Explorer: Shows formula, notes, and highlights positions on the fretboard.

Circle of Fifths: Click any segment for diatonic chords, relative minor, and intervals.

Ear Training

  • Modes: Interval Recognition, Chord ID, Note ID.
  • Press Play to hear the sample, select your answer. Streak and accuracy tracked per session.

Global Audio Controls

  • Master Volume — Controls final gain across all sources.
  • Mute — Silences all audio without stopping any engine. Click again to restore.
  • Now Playing pill — Appears when audio is active. Click the jump button to go to that screen.

Pipeline: Source → InstrumentGain → MasterGain → Compressor → Output

Tips

  • Audio starts on first user gesture — if silent, click any button first.
  • Fretboard supports left-handed mode — toggle in Settings.
  • Run python download_samples.py from the app/ folder to fetch CC0 guitar samples.
  • Works offline once loaded — no internet required after initial page load.
